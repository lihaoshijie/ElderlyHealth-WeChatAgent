第 1 页 · 封面

MyDemo Agent —— 跑在微信里的 AI 智能助手

  • 让微信拥有自己的 AI 助手：自然语言直达工具，无需下载 App，扫码即用
  • 项目答辩
  • 技术关键词：Spring Boot · LangChain4j · LLM Function Calling · MySQL · Vue 3
  • 一句话介绍：集成 74 个内置工具、RAG 知识库、图片理解与生成、MCP 外部工具，全部由大模型函数调用驱动，零硬编码关键词匹配

第 2 页 · 项目概述

  • 做什么：基于微信生态的智能助手 Bot，把"理解—规划—执行—回复"完整交给 LLM 函数调用
  • 核心形态：一条微信消息 → 自动选择合适工具 → 多轮执行 → 返回可操作结果
  • 覆盖场景：天气环境、健康管理、旅行出行、B站内容、新闻资讯、玄学命理、知识库问答、语音交互等 12+ 大域
  • 亮点一句话：工具即插即用，能力按需激活，用户只需会聊天

第 3 页 · 技术栈

  • 框架：Spring Boot 4.0.7 + MyBatis（Java 21）
  • 微信接入：wechat-ilink-sdk-java 2.3.3（iLink SDK）
  • LLM 调用：LangChain4j 0.36.2（OpenAiChatModel + Tokenizer）
  • 大模型：DashScope qwen3.6-flash（OpenAI 兼容接口）
  • 多模态：识图 qwen-vl-max / 文生图 wan2.6-t2i / 图生图 wanx2.1 / 语音 cosyvoice-v3-flash
  • 存储：MySQL 8.0（HikariCP + JdbcTemplate）+ 本地文件
  • 周边：Apache POI/PDFBox 文件解析、ZXing 二维码、高德地图、飞猪、12306 MCP（JSON-RPC）

第 4 页 · 整体架构

  • 接入层：iLink SDK 微信消息（文本/图片/语音/文件）→ 线程池(16)异步处理
  • 路由层：CommandRouter —— 域过滤 → LLM 规划 → 工具执行 → ReAct 循环
  • 工具层：ToolRegistry 注册 74 个 @Tool 工具 + 13 个 Skill + 12306 MCP 动态注册
  • 服务层：LLM 调用、对话历史、RAG 检索、Embedding 向量化、健康/旅游/语音等业务服务
  • 数据层：chat_history、admin_user_messages/images/files、doc_embeddings、agent_traces 等 11 张表
  • 展示层：Vue 3 管理后台（会话总览 / 图片 / 文件 / 知识库 / 能力展示页）

第 5 页 · 核心链路：Agent Loop（ReAct 循环）

  • 步骤 1：消息进入 → 工具域过滤（只发送相关域工具，闲聊仅 5 个）
  • 步骤 2：LLM 函数调用规划 → 返回 function_call 列表（可多个）
  • 步骤 3：工具并行执行（≥2 个时 CompletableFuture 并发）
  • 步骤 4：结果回填消息 → LLM 继续规划，最多 3 轮
  • 步骤 5：综合生成自然语言回复并发送
  • 示例："明天杭州天气怎么样" → 并行调 weather + local_time → "杭州明天晴天 28°C，适合出行"

  • 出行：景点 POI、行程规划、飞猪搜索、购票链接、订单管理
  • 命理：四柱八字、流年、五行喜忌、塔罗

第 7 页 · 亮点：动态工具分域

  • 问题：82 个工具全部发给 LLM，Token 消耗巨大、选择易错
  • 方案：输入关键词 → 匹配工具域 → 只发送相关工具
  • 效果：闲聊场景 Token 从 8500 降到 2500，响应更快、更准
  • 域内多工具同轮并行：5 秒耗时场景降到 2 秒

第 8 页 · 亮点：Agent 稳定性四重保护

  • 去重拦截：同一工具 + 同一参数只执行一次（防止重复调用）
  • Token 预算保护：累计超 100K 强制总结，不炸上下文
  • 总超时保护：单次任务 90 秒上限，超时强制收尾，不死循环
  • 工具结果截断：单条结果超 10000 字自动截断，多轮不膨胀
  • 预告兜底：LLM 只回"正在为您…"而未调工具时，自动追加指令重试
  • 搜索降级：百度不可用时自动切换 Google

第 9 页 · 亮点：Skill 技能编排系统

  • 机制：工具调用后自动激活对应行为规则，注入 LLM 上下文
  • 13 个技能示例：搜索自动生成二维码、旅游按流程出攻略、热搜追问必须调真数据、健康饮食查营养+建议、语音用完自动关闭、记忆主动保存用户信息
  • 效果：让模型在处理任务时"带上对应手册"，回复质量稳定可预期

第 10 页 · RAG 知识库问答

  • 流程：上传文件(PDF/Word/文本) → 提取 → 切块(1000字/100字重叠) → Embedding 向量化 → 入库
  • 检索：全文索引粗筛 + 向量精确匹配（向量 0.6 + BM25 0.4）
  • 工程细节：空库 TTL 缓存免调用、相似度 <0.45 预检拦截、注入限长 1500 字
  • 示例：上传《汇编语言程序设计》后，直接提问课件内容并基于文档回答
