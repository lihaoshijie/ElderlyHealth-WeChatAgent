跑在微信里的 AI 智能助手 —— 自然语言直达工具，扫码即用

Spring Boot LangChain4j LLM Function Calling Vue 3 MySQL

集成 74 个内置工具 · RAG 知识库 · 图片理解与生成 · MCP 外部工具

项目概述

让微信拥有自己的 AI 助手

  • 做什么：基于微信生态的智能助手 Bot，把"理解—规划—执行—回复"完整交给 LLM 函数调用
  • 核心形态：一条微信消息 → 自动选择合适工具 → 多轮执行 → 返回可操作结果
  • 覆盖场景：天气环境、健康管理、旅行出行、B站内容、新闻资讯、玄学命理、知识库问答、语音交互等 12+ 大域
  • 亮点：工具即插即用，能力按需激活，用户只需会聊天

亮点 · 工程优化

动态工具分域

优化前

82 个工具全部发给 LLM

Token 消耗巨大，选择易错，单次请求 8500 Token

优化后

只发送相关域工具

闲聊场景 Token 从 8500 降到 2500，响应更快更准；域内多工具同轮并行，5 秒耗时降到 2 秒

亮点 · 稳定性
